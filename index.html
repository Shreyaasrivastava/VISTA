Admin dashboard

Live density for the zones of your venue, the cameras feeding them, and the thresholds that decide when alerts fire. You only see your own venue.

Thresholds

Occupancy % = people ÷ (zone area × 1.08 people/m²). Severity needs 3 readings in a row before it changes. These are the defaults; each camera can set its own levels below.

Normal under 50%Caution 50 to 75% Warning 75 to 90%Critical 90% and above

Edit camera

Set up a new camera

  1. Enter the stream URL and pick the venue.
  2. Click four reference points of known distance on a frame.
  3. Check the computed ground-plane mapping.
  4. Draw the zone boundary this camera covers.
  5. Set the detection range in metres.
  6. Set Caution, Warning and Critical thresholds and total capacity.
