# Launch checklist

Do not launch until every box is ticked.

- [ ] Connect a custom domain (see README, "Deploy")
- [ ] Favicon: done (favicon.svg, favicon.ico, apple-touch-icon.png). Check it shows in the browser tab after deploy.
- [ ] No "Made with AI" tag: none is in these files. Check your host's dashboard has no badge turned on.
- [ ] Privacy policy (privacy.html) and Terms (terms.html): fill every `[[FILL: ...]]`, then search the whole project for `[[FILL` and confirm nothing is left.
- [ ] Have a lawyer read both pages. They are drafts, not legal advice. Make sure each statement is true for your real system (password hashing, retention, video storage, age rule).
- [ ] Domain placeholders: replace every `[[FILL: domain]]` (canonical links, Open Graph URLs, sitemap.xml, robots.txt, structured data) with your real domain, for example `example.com`. No `https://`, no trailing slash. Use find and replace across the whole folder.
- [ ] Google Search Console: add the property for your domain, verify it (DNS TXT record or the meta tag, placed where the comment in the head says), then submit `https://your-domain/sitemap.xml`.
- [ ] Optional: add a social preview image (`og:image`) only if it is a real photo or logo you own. None is included.
- [ ] Replace the simulated data with real camera data from the backend, then delete the "Prototype" notice in index.html.
- [ ] Delete the "Demo accounts" box on the login screen and the demo USERS in app.js. Real login must be JWT + roles in FastAPI, checking venue_id on every query.
- [ ] Replace the demo QR code with a real, scannable one generated by the backend.
