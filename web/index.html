    Thresholds

    Occupancy % = people divided by (zone area times the reference density). The server uses 1.08 people per m² as 100%. Each camera sets its own levels on the Cameras page. These are the defaults.

    Camera setup guide

    How to bring a new camera online. A camera can send readings only after step 5.

    1. Add the camera on the Cameras page and copy its ingest key. It is shown only once.
    2. On a frame from the camera, pick 4 or more floor points and measure their real positions in metres in your venue's coordinate system.
    3. Put the points in a points.json file and run python calibrate.py points.json from the vision folder. It prints the calibration error. Aim for under 0.25 m.
    4. Open the camera with Edit, then choose the camera_patch.json file under Calibration file.
    5. Start the vision service with the ingest key as VISTA_CAMERA_KEY. The zone shows live numbers within a few seconds.
